Claude Tasks privacy policy

Last updated: November 13, 2026

Claude Tasks is a personal tool used only by its owner, with the owner's own Google account.

What it accesses

With the owner's consent, it uses the Google Tasks scope (https://www.googleapis.com/auth/tasks) to read, create, update, complete and delete the owner's task lists and tasks.

How the data is used

Task data is used only to manage the owner's tasks and to include them in the owner's private daily briefing. It is processed on the owner's own computer and in the owner's own private services.

Storage and sharing

The sign-in token is stored only on the owner's computer, readable only by the owner's user account. Task data is not sold, not shared with third parties, not used for advertising, and not used to train AI models.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
